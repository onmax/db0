# Transactions

> Execute multiple database operations atomically with automatic commit/rollback.

DB0 provides two transaction styles: callback-based (recommended) and manual control.

## Callback Style (Recommended)

The callback style automatically commits on success and rolls back on error:

```ts
import { createDatabase } from "db0";
import sqlite from "db0/connectors/better-sqlite3";

const db = createDatabase(sqlite({}));

// All operations inside the callback are atomic
const result = await db.transaction(async (tx) => {
  await tx.sql`INSERT INTO accounts (id, balance) VALUES (1, 1000)`;
  await tx.sql`INSERT INTO accounts (id, balance) VALUES (2, 0)`;

  // Transfer funds
  await tx.sql`UPDATE accounts SET balance = balance - 100 WHERE id = 1`;
  await tx.sql`UPDATE accounts SET balance = balance + 100 WHERE id = 2`;

  // Return value is passed through
  return { transferred: 100 };
});

console.log(result); // { transferred: 100 }
```

If any operation throws an error, all changes are rolled back:

```ts
try {
  await db.transaction(async (tx) => {
    await tx.sql`UPDATE accounts SET balance = balance - 100 WHERE id = 1`;
    throw new Error("Something went wrong!");
    // The UPDATE above is automatically rolled back
  });
} catch (error) {
  console.error("Transaction failed:", error);
}
```

## Manual Style

For advanced control, use `beginTransaction()`:

```ts
const tx = await db.beginTransaction();

try {
  await tx.sql`INSERT INTO orders (id, status) VALUES (1, 'pending')`;
  await tx.sql`INSERT INTO order_items (order_id, product) VALUES (1, 'Widget')`;

  // Explicitly commit
  await tx.commit();
} catch (error) {
  // Explicitly rollback
  await tx.rollback();
  throw error;
}
```

## Transaction Object API

The transaction object (`tx`) provides the same query methods as the database:

| Method | Description |
|--------|-------------|
| `tx.sql\`...\`` | Execute query with tagged template |
| `tx.exec(sql)` | Execute raw SQL string |
| `tx.prepare(sql)` | Create prepared statement |
| `tx.commit()` | Commit transaction (manual mode) |
| `tx.rollback()` | Rollback transaction (manual mode) |

## Transaction Options

Both methods accept optional configuration:

```ts
await db.transaction(async (tx) => {
  // ...
}, {
  nested: true // Use SAVEPOINT for nested transactions (default: true)
});

const tx = await db.beginTransaction({
  nested: true
});
```

## Connector Support

Not all connectors support native transactions. Check capabilities:

```ts
if (db.capabilities.supportsTransactions) {
  await db.transaction(async (tx) => {
    // Safe to use
  });
}
```

If a connector doesn't have native transaction support, DB0 falls back to raw `BEGIN`/`COMMIT`/`ROLLBACK` SQL commands.
