# HTTP Server

> Expose any db0 database over HTTP for edge runtimes and remote access.

The HTTP server feature allows you to create an HTTP endpoint that exposes database operations, enabling edge runtimes to access backend databases through a secure API.

## Server Setup

Create an HTTP handler that wraps your database:

```ts
import { createDatabase } from "db0";
import sqlite from "db0/connectors/better-sqlite3";
import { createDatabaseHandler } from "db0/server";

const db = createDatabase(sqlite({ name: "app.db" }));

export default createDatabaseHandler({
  db,
  authorize: ({ event, type }) => {
    // Optional: Add authorization logic
    if (type === "write" && !isAuthorized(event)) {
      throw new Error("Unauthorized");
    }
  },
});
```

### Nuxt/Nitro Integration

Create a server route in your Nuxt/Nitro application:

```ts
// server/api/db.ts
import { createDatabase } from "db0";
import sqlite from "db0/connectors/better-sqlite3";
import { createDatabaseHandler } from "db0/server";

const db = createDatabase(sqlite({ name: "app.db" }));

export default defineEventHandler(
  createDatabaseHandler({
    db,
    authorize: async ({ event, type }) => {
      const session = await getUserSession(event);
      if (type === "write" && !session?.user?.isAdmin) {
        throw createError({ statusCode: 403, message: "Forbidden" });
      }
    },
  }),
);
```

## Client Setup

Connect to the HTTP server using the `http` connector:

```ts
import { createDatabase } from "db0";
import http from "db0/connectors/http";

const db = createDatabase(
  http({
    url: "https://my-app.com/api/db",
    headers: {
      Authorization: "Bearer your-token",
    },
  }),
);

// Use like any other db0 database
const { rows } = await db.sql`SELECT * FROM users`;
```

## API Reference

### Server Options

| Option | Type | Description |
|--------|------|-------------|
| `db` | `Database` | The db0 database instance to expose |
| `authorize` | `(req) => void \| Promise<void>` | Optional authorization callback |

### Authorization Callback

The `authorize` callback receives:

```ts
interface AuthorizeRequest {
  event: H3Event;        // The HTTP event
  type: "read" | "write"; // Operation type
}
```

Throw an error to deny access:

```ts
authorize: ({ event, type }) => {
  if (type === "write") {
    throw createError({ statusCode: 403 });
  }
}
```

### HTTP Client Options

| Option | Type | Description |
|--------|------|-------------|
| `url` | `string` | URL of the database server endpoint |
| `headers` | `Record<string, string>` | Optional headers (e.g., for authentication) |
| `dialect` | `SQLDialect` | SQL dialect hint. Default: `sqlite` |

## HTTP Protocol

### GET Request (Read-only queries)

```
GET /api/db?sql=SELECT * FROM users&params=[]
```

Query parameters:
- `sql`: The SQL query (must be SELECT/WITH/EXPLAIN)
- `params`: JSON-encoded array of parameters

Response:
```json
{ "rows": [...], "success": true }
```

### POST Request (All queries)

```
POST /api/db
Content-Type: application/json

{ "sql": "INSERT INTO users (name) VALUES (?)", "params": ["Alice"] }
```

Response:
```json
{ "success": true, "lastInsertRowid": 1, "changes": 1 }
```

## Security Considerations

1. **Always use HTTPS** in production
2. **Implement authorization** - the `authorize` callback is essential for production
3. **Use authentication headers** - pass tokens via the `headers` option
4. **Limit exposed operations** - consider restricting which tables/operations are allowed
5. **Rate limiting** - implement rate limiting at the server level

## Example: Full Stack Setup

### Server (Nitro)

```ts
// server/api/db.ts
import { createDatabase } from "db0";
import sqlite from "db0/connectors/better-sqlite3";
import { createDatabaseHandler } from "db0/server";

const db = createDatabase(sqlite({ name: ".data/app.db" }));

// Initialize schema
await db.sql`CREATE TABLE IF NOT EXISTS todos (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  completed INTEGER DEFAULT 0
)`;

export default defineEventHandler(
  createDatabaseHandler({
    db,
    authorize: async ({ event, type }) => {
      // Verify API key for writes
      if (type === "write") {
        const apiKey = getHeader(event, "x-api-key");
        if (apiKey !== process.env.API_KEY) {
          throw createError({ statusCode: 401 });
        }
      }
    },
  }),
);
```

### Client (Edge Runtime)

```ts
// composables/useDb.ts
import { createDatabase } from "db0";
import http from "db0/connectors/http";

export const useDb = () => {
  return createDatabase(
    http({
      url: "/api/db",
      headers: {
        "x-api-key": process.env.API_KEY!,
      },
    }),
  );
};
```

```ts
// Usage
const db = useDb();
const todos = await db.sql`SELECT * FROM todos WHERE completed = ${0}`;
```
