# Type Transformers

> Automatic type conversions between JavaScript and database types.

DB0 automatically transforms types based on database capabilities. This means you can use native JavaScript types (booleans, Dates, objects) and DB0 handles the conversion.

## How It Works

When a database doesn't natively support a type, DB0 transforms it:

| JavaScript Type | Unsupported DB Storage | Example |
|-----------------|----------------------|---------|
| `boolean` | Integer (0/1) | `true` → `1` |
| `Date` | ISO 8601 string | `new Date()` → `"2024-01-15T10:30:00.000Z"` |
| `object/array` | JSON string | `{a: 1}` → `'{"a":1}'` |

On output, DB0 transforms back:

| DB Value | JavaScript Type | Example |
|----------|----------------|---------|
| `1` / `0` | `boolean` | `1` → `true` (when known to be boolean) |
| ISO string | `Date` | `"2024-01-15T..."` → `Date` object |
| JSON string | `object/array` | `'{"a":1}'` → `{a: 1}` |

## Default Behavior

Transformers are enabled automatically when the database lacks native support:

```ts
import { createDatabase } from "db0";
import sqlite from "db0/connectors/better-sqlite3";

const db = createDatabase(sqlite({}));
// SQLite: booleans=true, dates=true, json=true (auto-enabled)

// These are automatically transformed for SQLite
await db.sql`INSERT INTO events (active, metadata, created_at)
  VALUES (${true}, ${{ type: 'click' }}, ${new Date()})`;
// Stored as: (1, '{"type":"click"}', '2024-01-15T10:30:00.000Z')

// On read, strings are transformed back
const { rows } = await db.sql`SELECT * FROM events`;
console.log(rows[0].created_at); // Date object
console.log(rows[0].metadata);   // { type: 'click' }
```

## Configuration

Override the automatic behavior:

```ts
const db = createDatabase(connector, {
  transformers: {
    booleans: true,  // Transform booleans ↔ integers
    dates: true,     // Transform dates ↔ ISO strings
    json: true,      // Transform objects ↔ JSON strings
    disabled: false  // Set true to disable all transformers
  }
});
```

### Disable All Transformers

```ts
const db = createDatabase(connector, {
  transformers: { disabled: true }
});

// Now you must handle conversions manually
await db.sql`INSERT INTO users (active) VALUES (${1})`; // Not true
```

### Override Specific Transformers

```ts
// PostgreSQL has native JSON but you want string storage
const db = createDatabase(pgConnector, {
  transformers: { json: true } // Force JSON string transformation
});
```

## Transformer Details

### Boolean Transformer

Converts `true`/`false` to `1`/`0` for databases like SQLite that store booleans as integers.

```ts
// Input
await db.sql`INSERT INTO users (active) VALUES (${true})`;
// SQLite receives: INSERT INTO users (active) VALUES (1)

// Output transformation requires schema knowledge
// DB0 transforms 1/0 back only when the column is known to be boolean
```

> Note: On output, integer → boolean conversion only happens when DB0 knows the column type. Raw integer values (`1`, `0`) remain as integers.

### Date Transformer

Converts `Date` objects to ISO 8601 strings and back.

```ts
const now = new Date();
await db.sql`INSERT INTO events (created_at) VALUES (${now})`;
// Stored as: '2024-01-15T10:30:00.000Z'

const { rows } = await db.sql`SELECT created_at FROM events`;
console.log(rows[0].created_at instanceof Date); // true
```

### JSON Transformer

Converts objects and arrays to JSON strings and back.

```ts
const metadata = { tags: ['important', 'urgent'], priority: 1 };
await db.sql`INSERT INTO tasks (metadata) VALUES (${metadata})`;
// Stored as: '{"tags":["important","urgent"],"priority":1}'

const { rows } = await db.sql`SELECT metadata FROM tasks`;
console.log(rows[0].metadata.tags); // ['important', 'urgent']
```
