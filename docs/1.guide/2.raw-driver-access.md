# Raw Driver Access

> Access the underlying database driver for advanced use cases and ORM composition.

## getInstance()

Use `getInstance()` to access the native database driver directly. This enables composing db0 with any ORM (Kysely, Prisma, TypeORM, etc.) without lock-in.

```ts
import { createDatabase } from "db0";
import postgresql from "db0/connectors/postgresql";

const db = createDatabase(postgresql({ url: "postgres://..." }), { eager: true });

// Wait for connection
await db.ready();

// Get the native pg.Client instance
const pgClient = db.getInstance();

// Use directly with pg API
const result = await pgClient.query("SELECT NOW()");
```

## Typed Driver Instances

Each connector returns a properly typed native driver:

| Connector | Instance Type |
|-----------|---------------|
| `better-sqlite3` | `Database.Database` |
| `postgresql` | `pg.Client` |
| `mysql2` | `mysql.Connection` |
| `pglite` | `PGlite` |
| `libsql` | `Client` |
| `cloudflare-d1` | `D1Database` |

## ORM Composition Patterns

### Kysely

```ts
import { createDatabase } from "db0";
import postgresql from "db0/connectors/postgresql";
import { Kysely, PostgresDialect } from "kysely";

const db0 = createDatabase(postgresql({ url: "postgres://..." }), { eager: true });
await db0.ready();

// Use db0's connection with Kysely
const kysely = new Kysely({
  dialect: new PostgresDialect({
    pool: db0.getInstance(), // Pass pg.Client to Kysely
  }),
});

// Use Kysely's query builder
const users = await kysely.selectFrom("users").selectAll().execute();
```

### Prisma

```ts
import { createDatabase } from "db0";
import postgresql from "db0/connectors/postgresql";
import { PrismaClient } from "@prisma/client";

// db0 manages connection, Prisma uses its own pool
const db0 = createDatabase(postgresql({ url: "postgres://..." }), { eager: true });
await db0.ready();

// For raw queries, use getInstance()
const client = db0.getInstance();
const result = await client.query("SELECT * FROM _prisma_migrations");

// Prisma can coexist - same database, separate connection
const prisma = new PrismaClient();
const users = await prisma.user.findMany();
```

### TypeORM

```ts
import { createDatabase } from "db0";
import mysql from "db0/connectors/mysql2";
import { DataSource } from "typeorm";

const db0 = createDatabase(mysql({ host: "localhost", database: "test" }), { eager: true });
await db0.ready();

// Access raw mysql2 connection for custom operations
const connection = db0.getInstance();

// TypeORM DataSource for entity management
const dataSource = new DataSource({
  type: "mysql",
  host: "localhost",
  database: "test",
});
```

## Eager vs Lazy Initialization

By default, `getInstance()` returns a Promise. Enable `eager` mode for synchronous access after `ready()`:

```ts
// Lazy (default) - getInstance() returns Promise
const db = createDatabase(connector);
const instance = await db.getInstance();

// Eager - getInstance() returns synchronously after ready()
const db = createDatabase(connector, { eager: true });
await db.ready();
const instance = db.getInstance(); // Sync!
```

## Best Practices

1. **Use eager mode** when you need synchronous driver access
2. **Call `ready()`** before accessing the instance in eager mode
3. **Let db0 manage the connection lifecycle** - use `dispose()` for cleanup
4. **Type safety** - TypeScript infers the correct driver type from the connector
