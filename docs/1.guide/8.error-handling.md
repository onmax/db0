# Error Handling

> Structured error classes for database operations.

DB0 provides typed error classes for consistent error handling across all connectors.

## Error Classes

### DatabaseError

Base class for all DB0 errors:

```ts
import { DatabaseError } from "db0";

try {
  await db.sql`SELECT * FROM nonexistent`;
} catch (error) {
  if (error instanceof DatabaseError) {
    console.log(error.code);    // Error code
    console.log(error.message); // Error message
    console.log(error.cause);   // Original error (if wrapped)
  }
}
```

### ConnectionError

Thrown for connection-related failures:

```ts
import { ConnectionError } from "db0";

try {
  const db = createDatabase(connector);
  await db.sql`SELECT 1`;
} catch (error) {
  if (error instanceof ConnectionError) {
    console.log("Failed to connect:", error.message);
    // error.code: 'CONNECTION_FAILED' | 'CONNECTION_CLOSED' | 'CONNECTION_TIMEOUT'
  }
}
```

### TransactionError

Thrown for transaction failures:

```ts
import { TransactionError } from "db0";

try {
  await db.transaction(async (tx) => {
    await tx.sql`UPDATE accounts SET balance = -100 WHERE id = 1`;
  });
} catch (error) {
  if (error instanceof TransactionError) {
    console.log("Transaction failed:", error.message);
    // error.code: 'TRANSACTION_FAILED' | 'TRANSACTION_ALREADY_COMMITTED' | 'TRANSACTION_ALREADY_ROLLED_BACK'
  }
}
```

### ValidationError

Thrown for data validation failures:

```ts
import { ValidationError } from "db0";

try {
  await adapter.model('users').create({ data: invalidData });
} catch (error) {
  if (error instanceof ValidationError) {
    console.log("Validation failed:", error.message);
    // error.code: 'VALIDATION_FAILED' | 'TYPE_MISMATCH' | 'SCHEMA_MISMATCH'
  }
}
```

## Error Codes

| Code | Description |
|------|-------------|
| `CONNECTION_FAILED` | Initial connection failed |
| `CONNECTION_CLOSED` | Operation on closed connection |
| `CONNECTION_TIMEOUT` | Connection timed out |
| `TRANSACTION_FAILED` | Transaction operation failed |
| `TRANSACTION_ALREADY_COMMITTED` | Attempted operation after commit |
| `TRANSACTION_ALREADY_ROLLED_BACK` | Attempted operation after rollback |
| `VALIDATION_FAILED` | Data validation failed |
| `TYPE_MISMATCH` | Type doesn't match expected |
| `SCHEMA_MISMATCH` | Data doesn't match schema |
| `QUERY_FAILED` | Query execution failed |
| `UNKNOWN` | Unclassified error |

## Error Properties

All error classes share these properties:

```ts
interface DatabaseError extends Error {
  code: DatabaseErrorCode;  // Error code (see table above)
  message: string;          // Human-readable message
  cause?: Error;            // Original error if wrapped
  name: string;             // 'DatabaseError', 'ConnectionError', etc.
}
```

## Usage Patterns

### Catching Specific Errors

```ts
import { ConnectionError, TransactionError, DatabaseError } from "db0";

try {
  await db.transaction(async (tx) => {
    await tx.sql`INSERT INTO users (email) VALUES (${email})`;
  });
} catch (error) {
  if (error instanceof ConnectionError) {
    // Handle connection issues - maybe retry
    console.log("Connection issue, retrying...");
  } else if (error instanceof TransactionError) {
    // Transaction-specific handling
    console.log("Transaction failed:", error.code);
  } else if (error instanceof DatabaseError) {
    // Generic database error
    console.log("Database error:", error.message);
  } else {
    throw error; // Re-throw unknown errors
  }
}
```

### Error Code Checking

```ts
try {
  await db.sql`SELECT * FROM users`;
} catch (error) {
  if (error instanceof DatabaseError) {
    switch (error.code) {
      case 'CONNECTION_CLOSED':
        await reconnect();
        break;
      case 'QUERY_FAILED':
        logQuery(error);
        break;
      default:
        throw error;
    }
  }
}
```

### Accessing Original Error

```ts
try {
  await db.sql`INVALID SQL`;
} catch (error) {
  if (error instanceof DatabaseError && error.cause) {
    // Access the original driver error
    console.log("Original error:", error.cause.message);
    console.log("Wrapped as:", error.message);
  }
}
```

## TypeScript Types

Import error types for type-safe error handling:

```ts
import {
  DatabaseError,
  ConnectionError,
  TransactionError,
  ValidationError,
  type DatabaseErrorCode,
  wrapError,
  wrapConnectionError,
  wrapTransactionError,
} from "db0";
```

### Error Wrapping Utilities

Wrap unknown errors into typed DatabaseError:

```ts
try {
  await someOperation();
} catch (error) {
  throw wrapError(error, "Operation failed", "QUERY_FAILED");
}
```
