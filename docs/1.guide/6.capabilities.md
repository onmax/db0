# Capability Flags

> Query database feature support at runtime.

Each database has different native capabilities. DB0 exposes these through the `db.capabilities` object, allowing you to adapt your code accordingly.

## Accessing Capabilities

```ts
import { createDatabase } from "db0";
import sqlite from "db0/connectors/better-sqlite3";

const db = createDatabase(sqlite({}));

console.log(db.capabilities);
// {
//   supportsJSON: true,
//   supportsBooleans: false,
//   supportsArrays: false,
//   supportsDates: false,
//   supportsUUIDs: false,
//   supportsTransactions: true,
//   supportsBatch: true
// }
```

## Available Flags

| Flag | Description |
|------|-------------|
| `supportsJSON` | Native JSON column type and operations |
| `supportsBooleans` | Native boolean type (vs integer 0/1) |
| `supportsArrays` | Array columns |
| `supportsDates` | Native date/timestamp columns |
| `supportsUUIDs` | Native UUID type |
| `supportsTransactions` | Transaction support |
| `supportsBatch` | Batch operations |

## Usage Patterns

### Conditional Feature Usage

```ts
// Check before using arrays
if (db.capabilities.supportsArrays) {
  await db.sql`INSERT INTO posts (tags) VALUES (${['news', 'tech']})`;
} else {
  await db.sql`INSERT INTO posts (tags) VALUES (${JSON.stringify(['news', 'tech'])})`;
}
```

### Runtime Adaptation

```ts
function insertUser(db, user) {
  // Boolean handling differs by database
  const isActive = db.capabilities.supportsBooleans
    ? user.isActive
    : user.isActive ? 1 : 0;

  return db.sql`INSERT INTO users (name, active) VALUES (${user.name}, ${isActive})`;
}
```

## Type Transformers

DB0 can automatically handle type conversions based on capabilities. See [Type Transformers](/guide/type-transformers) for automatic boolean, date, and JSON handling.
