## Model API

All three adapters (Drizzle, Prisma, Kysely) provide a consistent Model API:

```ts
const users = adapter.model('users');

// Common operations across all adapters
await users.findOne({ where: { id: 1 } });
await users.findMany({ where: { active: true }, limit: 10 });
await users.create({ data: { name: 'John', email: 'john@example.com' } });
await users.update({ where: { id: 1 }, data: { name: 'Jane' } });
await users.delete({ where: { id: 1 } });
await users.count({ where: { active: true } });
```

Each adapter also exposes the native ORM instance for complex queries:

```ts
// Drizzle
const { native } = drizzleAdapter(db, schema);
await native.select().from(users).leftJoin(posts, ...);

// Prisma
const { native } = prismaAdapter(prisma);
await native.user.findMany({ include: { posts: true } });

// Kysely
const { native } = kyselyAdapter(kysely);
await native.selectFrom('users').leftJoin('posts', ...).execute();
```
