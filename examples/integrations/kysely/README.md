# Kysely Integration Example

Using Kysely query builder with db0's kyselyAdapter.

## Requirements

- Node.js 18+

## Run

```bash
pnpm install
pnpm start
```

## What it shows

- Creating Kysely instance with SQLite
- Wrapping with `kyselyAdapter()`
- Unified model API for CRUD operations
- Transaction support
- Type-safe database schema with TypeScript
