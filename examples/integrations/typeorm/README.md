# TypeORM Integration Example

Using TypeORM with db0's typeormAdapter.

## Requirements

- Node.js 18+

## Run

```bash
pnpm install
pnpm start
```

## What it shows

- Creating TypeORM DataSource with SQLite
- Wrapping with `typeormAdapter()`
- Entity-based configuration with decorators
- Unified model API for CRUD operations
- Transaction support
