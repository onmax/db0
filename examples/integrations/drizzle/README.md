# Drizzle Integration Example

Using Drizzle ORM with db0.

## Requirements

- Node.js 18+

## Run

```bash
pnpm install
pnpm start
```

## What it shows

- Creating db0 database with better-sqlite3
- Wrapping with `drizzle()` integration
- Type-safe queries with Drizzle ORM
- Schema definition with drizzle-orm/sqlite-core
